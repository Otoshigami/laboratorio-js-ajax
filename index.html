Cuatro ejercicios sobre cadenas y números resueltos con JavaScript puro, y un cliente AJAX que muestra cada fase de una petición HTTP: estados, cabeceras, código y contenido.

AJAX

La petición se hace con XMLHttpRequest, que expone cada cambio de readyState. Por defecto se descarga esta misma página.

Probar con:

Abriste la página como archivo local (file://) y el navegador bloquea las peticiones AJAX desde ese origen. Sírvela por HTTP, por ejemplo con python -m http.server 8000, y abre http://localhost:8000.
